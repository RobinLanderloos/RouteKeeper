# Map tiles

Map art the game client lacks, used in place of the game's own tiles
(`Dungeons.ownArt` in `Core/Dungeons.lua`).

## WailingCaverns

The Wailing Caverns map from before patch 4.1, with the eastern maze that
Blizzard later cut from the dungeon. WoW Forever still has the whole cave, but
its client ships the 4.1 map. Same 1002x668 frame as the game's map, so
positions on it are the same.

- Art: © Blizzard Entertainment, from the World of Warcraft client.
- Files: the 12 tiles `WailingCaverns1_1.blp` … `_12.blp`, unchanged, from
  WDM-patch by Trimitor (https://github.com/Trimitor/WDM-patch), as vendored in
  https://github.com/Hisha/mod-native-instance-maps at commit
  87fe6faac20703310b14540ee05f5ea4285ca89c
  (`upstream/WDM-patch/Stable/enUS/Interface/WorldMap/WailingCaverns/`).
- The same map is on Warcraft Wiki as `WorldMap-WailingCaverns-old.jpg`.
